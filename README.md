# スタディングキャリア 再構築資料

現行サービスの調査結果、要件定義のたたき台、公開ページの保存本文、画面のスクリーンショットを管理します。調査日：2026年10月21日。

## 新サービスの構想

- [シンプル版LPのソースと使い方](simple-lp/README.md) — 登録前の求人閲覧、資格の絞り込み、求人詳細、登録フォームを実装した試作版。
- [初期リリース要件](docs/初期リリース要件.md) — 1ページのLPと申込フォームから開始し、人による面談・求人紹介で運営する最小構成。
- [コンセプト構想 2026年10月22日](docs/コンセプト構想.md) — 学習からの送客、応募前の対話、国内外サービス比較、大胆な発展案、検証計画。

現行仕様の整理に対し、新サービスの構想は検討段階の提案です。推奨する方向は「学びが伝わる転職サービス」を土台に、「合格前から企業と話せるキャリアネットワーク」を育てることです。

## 調査の範囲

公開情報で確認した現行仕様と、新システムへの提案・社内確認事項を区別しています。ログイン後の動作、企業・運営管理画面、DB・契約の詳細は未確認です。スクリーンショットは表示の証跡であり、動作確認の完了を意味しません。

フォームトークン等を含み得る原HTML、未加工manifest、MHTML、ZIP、確認用の派生画像はGit対象から除外しています。公開ページの保存本文は `research_20261021/sources/*.txt`、取得済み画像は `research_20261021/assets/` にあります。元サイトの完全バックアップではありません。
