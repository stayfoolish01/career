# スタディングキャリア シンプル版LP

2026年10月22日作成。旧サービスのブランドを参考にした、求人閲覧と会員登録導線のプロトタイプ。

## 開く

**チームへの共有には [単一HTML版](スタディングキャリア_共有用.html) を使ってください。** この1ファイルにCSS・JavaScript・画像を含みます。ダウンロードしてブラウザで開くだけで操作でき、サーバーやログイン、ネット接続は不要です。メール添付や社内のファイル共有で配布できます。プレビュー機能がHTMLを実行しない場合は、ファイルを保存してからEdge・Chrome等で開いてください。

[ページ本体](index.html) をダウンロード後、ブラウザで開いてください。ローカルサーバーでも確認できます。

```powershell
python -m http.server 8765 --directory simple-lp
```

ブラウザで `http://localhost:8765/` を開きます。

## 実装内容

- 資格別のサンプル求人6件と絞り込み。
- 求人詳細のダイアログ。
- 気になる求人を登録フォームへ引き継ぎ。
- 氏名、メール、資格、勤務地、希望、自由記入のフォーム。
- 必須入力・メール形式の確認と内容確認画面。
- 「情報収集」「相談」「求人紹介」の選択。
- FAQと説明ダイアログ。
- PC・スマートフォンに対応。

求人はすべて架空で、企業の募集や実際の給与を示しません。フォームは試作で、情報を送信・保存せず、メール認証・受付メール・実際の会員登録は行いません。実際の個人情報は入力しないでください。正式公開前に受付基盤、メール認証、実求人、利用条件、個人情報の取扱い、運営連絡先を接続・確定する必要があります。

## ファイル

- `index.html`：ページ構成。
- `style.css`：デザインとレスポンシブ表示。
- `app.js`：サンプル求人と画面操作。
- `assets/`：既存資料から取得したロゴ・サービス画像。
- `preview/`：PC・スマートフォンの確認画像。
- `スタディングキャリア_共有用.html`：画像等を内蔵した、オフラインで操作できる単一ファイル版。
- `build_standalone.py`：単一HTML版の生成。元ファイルの変更後に `python simple-lp/build_standalone.py` で更新します。

## 検証結果

Chromiumで1440px、768px、390pxの画面幅を確認。求人絞り込み、詳細、選択求人の引継ぎ、必須入力、入力文字列の安全な表示、完了時のフォーム消去を確認しました。ブラウザのlocalStorage・sessionStorageへの保存や、登録情報の送信はありません。

ホスティング用の作業ディレクトリはGit対象外の `sites/career-lp`。このディレクトリはレビュー用ソースの保存先です。改修時は両方を一致させてから公開します。
